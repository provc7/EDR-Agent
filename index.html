Step 1 — Wazuh Agent Installation
1

Name your agent & generate the install command

Enter a unique name for this endpoint — it will identify the machine in your Wazuh dashboard.

powershell — administrator 

          


          

            ⚠️
            

              Run as Administrator
              Right-click PowerShell → Run as administrator, paste the command above, and press Enter.
            

          

        

      


      
      

        

          
2

          

        

        

          
Wait for installation to complete

          
The command silently downloads the MSI and installs the agent — about 30 seconds. No progress window will appear; wait until the terminal prompt returns.

          
The agent registers itself with the Wazuh Manager at 10.20.8.34 during this step.

        

      


      
      

        

          
3

          

        

        

          
Start the Wazuh service

          
In the same elevated PowerShell window, run:

          

            

              powershell
              
            

            
            
NET START Wazuh

          

          

            ℹ️
            

              Expected output
              You should see "The Wazuh service was started successfully."

Step 2 — SilkETW Setup


    

      🔬
      

        What this does
        SilkETW hooks into Windows Event Tracing (ETW) to capture kernel-level telemetry — process creation, DNS queries, PowerShell activity, AMSI events, and more — writing structured JSON logs that Wazuh ingests for detection.
      

    


    


      
      

        

          
1

          

        

        

          
Download the setup script

          
Click below to download the automated SilkETW installer. Save it somewhere easy to reach — your Desktop or C:\ works fine.

          

            
              
              Download Setup-SilkETW.ps1
            
          

          

            📋
            

              What the script does
              Downloads the latest SilkETW from GitHub, installs VC++ runtime if missing, configures 11 ETW collectors (DNS, PowerShell, AMSI, Kerberos, NTLM, WMI, .NET, kernel process/file/registry, LDAP), and starts SilkService automatically.
            

          

        

      


      
      

        

          
2

          

        

        

          
Unblock the script

          
Windows blocks scripts downloaded from the internet by default — this one command removes that restriction so PowerShell can run it.

          
In an elevated PowerShell, navigate to where you saved the file and run:

          

            

              powershell — administrator
              
            

            
            
Unblock-File .\Setup-SilkETW.ps1

          

        

      


      
      

        

          
3

          

        

        

          
Run the setup script

          
Execute with Bypass execution policy so it runs without restriction:

          

            

              powershell — administrator
              
            

            
            
powershell -ExecutionPolicy Bypass -File .\Setup-SilkETW.ps1

          

          

            ℹ️
            

              Expected output
              The script runs 8 steps and ends with "SilkETW Setup Complete". JSON logs will start appearing in C:\edr\.
            

          

          

            ⚠️
            

              VC++ prompt
              If the Visual C++ 2015–2022 Redistributable (x86) is missing, the script will ask to install it — type Y and press Enter.
