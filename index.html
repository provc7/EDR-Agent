Install your
Wazuh agent

Enter a name for this endpoint, copy the generated command, and follow the steps below. Once Wazuh is running, set up Sysmon to start collecting telemetry.

Step 1 — Wazuh Agent Installation
1

Name your agent & generate the install command

Enter a unique name for this endpoint — it will identify the machine in your Wazuh dashboard.

powershell — administrator 

            


            

              ⚠️
              

                Run as Administrator
                Right-click PowerShell → Run as administrator, paste the command above, and press Enter.
              

            

          

        


        
        

          

            
2

            

          

          

            
Wait for installation to complete

            
The command silently downloads the MSI and installs the agent — about 30 seconds. No
              progress window will appear; wait until the terminal prompt returns.

            
The agent registers itself with the Wazuh Manager at 172.16.20.62 during this step.

          

        


        
        

          

            
3

            

          

          

            
Start the Wazuh service

            
In the same elevated PowerShell window, run:

            

              

                powershell
                
              

              
              
NET START Wazuh

            

            

              ℹ️
              

                Expected output
                You should see "The Wazuh service was started successfully."
              

            

          

        


      

    


    
    

      
Verify Agent Connection

      

        

          A
          

            
Check service status on the endpoint

            
In PowerShell: Get-Service Wazuh — Status should show Running.

          

        

        

          B
          

            
List agents on the Wazuh Manager

            
SSH into 172.16.20.62 and run /var/ossec/bin/agent_control -l. Your agent
              should appear as Active.

          

        

        

          C
          

            
Confirm in the Wazuh Web UI

            
Open the Wazuh dashboard → Agents. Your registered agent should appear with a green
              Active badge.

          

        

      

    


    
    

      

      Next — Sysmon Telemetry
      

    


    
    

      
Step 2 — Sysmon Setup


      

        🔬
        

          What this does
          Sysmon (System Monitor) is a Windows system service that logs detailed telemetry to the Windows Event Log —
          process creation with full command lines, network connections, image loads, and more. Wazuh reads these
          events in real time and forwards them to the manager for detection and correlation.
        

      


      


        
        

          

            
1

            

          

          

            
Download the setup script

            
Click below to download the Sysmon installer script. Save it somewhere easy to reach — your Desktop
              or C:\ works fine.

            

              
                
                Download Install-Sysmon.ps1
              
            

            

              📋
              

                What the script does
                Downloads the latest Sysmon release from Sysinternals, installs it as a Windows service, deploys a
                hardened XML configuration (process creation, network connections, image loads, PowerShell visibility),
                and verifies the service is running.
              

            

          

        


        
        

          

            
2

            

          

          

            
Open PowerShell as Administrator

            
Right-click the Start menu and select Windows PowerShell (Admin) or
              Terminal (Admin). Navigate to the folder where you saved the script:

            

              

                powershell — administrator
                
              

              
              
cd $env:USERPROFILE\Desktop

            

          

        


        
        

          

            
3

            

          

          

            
Bypass execution policy for this session

            
This allows the script to run in the current PowerShell session without permanently changing system
              policy. It applies only to the process scope and resets when the window is closed.

            

              

                powershell — administrator
                
              

              
              
Set-ExecutionPolicy Bypass -Scope Process -Force

            

          

        


        
        

          

            
4

            

          

          

            
Run the setup script

            
Execute the installer. It will download Sysmon, apply the configuration, and start the service
              automatically:

            

              

                powershell — administrator
                
              

              
              
.\Install-Sysmon.ps1

            

            

              ℹ️
              

                Expected output
                The script runs 4 steps and ends with "Sysmon Setup Complete". Events will start appearing
                in Event Viewer → Applications and Services Logs → Microsoft → Windows → Sysmon → Operational
                and forwarding to Wazuh automatically.
              

            

            

              ⚠️
              

                UAC prompt
                Windows will show a User Account Control prompt when Sysmon registers as a kernel driver — click
                Yes to allow.
